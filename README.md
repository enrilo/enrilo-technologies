# Enrilo Technologies — website

Next.js 16 (App Router) + Tailwind CSS site for Enrilo Technologies, the
parent company behind AcadTracker. Plain JavaScript — no TypeScript.

## Setup

```bash
npm install
cp .env.local.example .env.local
# then edit .env.local with your real GA4 Measurement ID
npm run dev
```

## What's included

- **Pages:** homepage (hero, about, services, how we work, AcadTracker
  product section, contact), `/privacy`, `/terms`, and a custom `/not-found`
  (404) page
- **SEO:** per-page `<title>`/description via the Metadata API, a `keywords`
  list in `app/layout.jsx`, Open Graph tags (card image auto-generated by
  `app/opengraph-image.js`), a canonical URL, a web app manifest and full
  favicon/icon set, and an Organization + SoftwareApplication + WebSite
  JSON-LD block describing Enrilo Technologies and AcadTracker. The only
  social channel linked is LinkedIn (company page, product showcase page,
  and founder profiles) — there is no Twitter/X presence, so no Twitter
  card metadata is emitted
- **Google Analytics 4:** `components/GoogleAnalytics.jsx` loads gtag.js
  site-wide, driven entirely by `NEXT_PUBLIC_GA_MEASUREMENT_ID` — set it in
  `.env.local` (never hardcode the ID in code), gated by the
  `CookieConsent` banner via Google Consent Mode v2
- **`sitemap.xml` and `robots.txt`:** generated dynamically from the
  hardcoded `siteUrl` in `app/sitemap.js` and `app/robots.js`
- **Design:** a "drafting studio" visual identity (ink navy + brass on cool
  paper, IBM Plex Serif/Sans, ruled hairlines and a hero schematic) rather
  than a generic SaaS template

## Before you publish

- If the production domain ever changes, update the hardcoded `siteUrl` in
  `app/layout.jsx`, `app/sitemap.js`, and `app/robots.js`
- The contact form (`components/ContactForm.jsx`) submits via Formspree —
  update `FORMSPREE_FORM_ID` if you move to a different form or endpoint

## Build

```bash
npm run build
npm start
```
